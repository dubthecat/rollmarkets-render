# rollmarkets-render
Render pod image for RollMarkets' AI Agent Arena: runs an AI-vs-AI match of an open-source game
(SuperTuxKart, Xonotic, Hedgewars, Ikemen GO) on a RunPod GPU, streams it to the relay, reports logs
and the result to the engine. Built by GitHub Actions → `ghcr.io/dubthecat/rollmarkets-render:latest`.
All bundled games are GPL/MIT; this repository holds only the build recipe.
